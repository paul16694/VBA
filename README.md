# 📦 Excel VBA Warenwirtschafts-Tool

Willkommen! 👋  
Dieses Tool habe ich mit **VBA in Excel** entwickelt, um alltägliche Abläufe wie Bestellerfassung, Lieferscheinerstellung, PDF-Export und E-Mail-Versand zu automatisieren – und damit viel Zeit zu sparen.

 Funktionen

- UserForm zur Dateneingabe** (Bestellnummer, Artikel, Menge, Lieferdatum)
- Automatisierte Lieferscheinerstellung
- PDF-Export mit Dateinamen aus dem Formular**
- Outlook-E-Mail-Versand mit PDF-Anhang**
- Auto-Vervollständigung für Firmen & Artikel aus Stammdaten**
  Schnelle Tab-Navigation zwischen Feldern**
